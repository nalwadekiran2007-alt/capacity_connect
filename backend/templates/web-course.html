Web Development

Learn HTML, CSS and JavaScript and build modern websites.

Lesson 1: HTML Basics

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

  • Headings
  • Paragraphs
  • Links
  • Images
  • Forms
<h1>Hello World</h1>
<p>Welcome to my website.</p>

Lesson 2: CSS Basics

CSS stands for Cascading Style Sheets. It is used to design and style web pages.

  • Colors
  • Fonts
  • Spacing
  • Layouts
  • Responsive design
body {
    font-family: Arial;
    background: white;
}

Lesson 3: JavaScript Basics

JavaScript is used to make web pages interactive and dynamic.

let name = "Kiran";
console.log("Hello " + name);

Lesson 4: HTML Forms

Forms are used to collect information from users.

<form>
    <input type="text" placeholder="Name">
    <button>Submit</button>
</form>

Lesson 5: Responsive Web Design

Responsive design makes websites work properly on mobile phones, tablets and computers.

  • Flexible layouts
  • Mobile-friendly design
  • Media queries
  • Responsive images
