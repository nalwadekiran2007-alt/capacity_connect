Java Programming

Learn Java programming from basics to object-oriented concepts.

Lesson 1: Introduction to Java

Java is a popular object-oriented programming language. It is used for application development, web applications and enterprise software.

  • Object-oriented programming language
  • Platform independent
  • Secure and reliable
  • Widely used in software development

Lesson 2: Variables and Data Types

Variables are used to store data. Java supports different data types such as int, double, char and boolean.

int age = 18;
double marks = 85.5;
char grade = 'A';
boolean passed = true;

Lesson 3: If-Else

If-else statements are used to make decisions in a Java program.

int age = 18;

if (age >= 18) {
    System.out.println("Eligible");
} else {
    System.out.println("Not Eligible");
}

Lesson 4: Loops

Loops are used to execute a block of code repeatedly.

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Lesson 5: Classes and Objects

A class is a blueprint for creating objects. An object is an instance of a class.

class Student {
    String name;
    int age;
}

Student s1 = new Student();
